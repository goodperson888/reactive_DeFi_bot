## Reactive Frontend

这个目录是 `reactive` 仓库里的 Next.js 前端，服务于同一个合约项目。

## 启动方式

推荐在仓库根目录运行：

```bash
cd ..
npm run frontend:dev
```

如果你已经在当前目录，也可以直接运行：

```bash
npm run dev
```

默认地址是 `http://localhost:3000`。

## 常用命令

```bash
# 安装前端依赖
npm install

# 本地开发
npm run dev

# 构建
npm run build

# 生产启动
npm run start

# 检查 lint
npm run lint
```

合约相关说明和完整项目结构见仓库根目录 `README.md`。
